# A/B-тест новой формы оплаты ЖКХ

## Описание проекта

Проект посвящён анализу результатов A/B-тестирования новой формы оплаты жилищно-коммунальных услуг (ЖКХ).

Цель исследования — определить, повышает ли новая форма вероятность успешного завершения оплаты по сравнению с существующей версией.

Эксперимент проводился с 1 по 30 апреля 2024 года.

Пользователи были случайным образом распределены между двумя группами:

- **A (контрольная)** — существующая форма оплаты.
- **B (тестовая)** — новая форма оплаты.

Единица рандомизации — пользователь. Один пользователь мог совершить несколько попыток оплаты.

## Данные

Исходный Excel-файл содержит два листа:

**Пользователи** — идентификатор пользователя, экспериментальная группа, возраст, город и тип устройства.

**Платежи** — идентификатор платежа, идентификатор пользователя, экспериментальная группа и временные отметки прохождения четырёх этапов оплаты.

Воронка оплаты состоит из следующих этапов:

1. Открытие формы.
2. Ввод реквизитов.
3. Подтверждение оплаты.
4. Успешное завершение оплаты.

## Этапы анализа

### 1. Проверка и очистка данных

Проверены пропущенные значения, дубликаты, корректность экспериментальных групп, возраст пользователей, соответствие групп в двух таблицах, даты платежей и последовательность прохождения этапов.

В ходе очистки:
- Исключён один пользователь с некорректной группой.
- Исключён один платёж без `user_id`.
- Аномальные значения возраста заменены на `NaN`.
- При несовпадении групп использовано назначение из таблицы пользователей.

После очистки осталось 1 503 пользователя и 2 660 попыток оплаты.

### 2. Анализ продуктовых метрик

Рассчитаны:
- Конверсия попыток в успешную оплату.
- Накопительная и пошаговая конверсии.
- Потери на этапах воронки.
- Количество активных пользователей.
- Среднее количество попыток на активного пользователя.
- Доля активных пользователей с хотя бы одной успешной оплатой.
- Абсолютный и относительный прирост конверсии.

**Основная метрика** — доля попыток, завершившихся успешной оплатой, среди всех открытий формы.

### 3. Статистическая проверка

Проверялась нулевая гипотеза об отсутствии различий между экспериментальными группами.

Для анализа использованы:

- **Кластерный bootstrap по пользователям** — для оценки 95% доверительного интервала разницы конверсий.
- **Перестановочный тест на уровне пользователей** — для оценки статистической значимости наблюдаемого различия.
- **Критерий хи-квадрат (SRM)** — для проверки соответствия размеров групп ожидаемому распределению 50/50.

Методы на уровне пользователей выбраны потому, что один пользователь мог совершить несколько зависимых попыток оплаты.

Для bootstrap и перестановочного теста использовано по 10 000 повторений, генератор случайных чисел инициализирован значением `42`. Уровень значимости — 0,05.

## Основные результаты

| Метрика | Группа A | Группа B |
|---|---:|---:|
| Попытки оплаты | 1 309 | 1 351 |
| Успешные оплаты | 652 | 870 |
| Конверсия попыток | 49,81% | 64,40% |
| Конверсия активных пользователей | 65,78% | 80,40% |

Абсолютный прирост основной конверсии составил **14,59 процентного пункта**, относительный — **29,29%**.

95% bootstrap-доверительный интервал разницы конверсий: **[10,89; 18,22] п.п.**

Перестановочный тест: **p-value = 0,000100**.

SRM-тест: **p-value = 0,979422**.

## Вывод

Новая форма оплаты продемонстрировала более высокую конверсию в успешную оплату по сравнению с контрольной формой.

Различие статистически значимо при уровне значимости 5%. Доверительный интервал прироста конверсии полностью находится выше нуля.

Проверка SRM не выявила статистически значимого отклонения размеров групп от ожидаемого соотношения 50/50.

Результаты поддерживают внедрение новой формы при условии дополнительной проверки технических и продуктовых рисков.
